# 🧳 어디 갈까 — 우리나라 여행 지도

전국 관광지 **228곳**을 지도에 표시하고, 누르면 **설명 · 가는 법 · 주변 맛집**을 보여줍니다.

👉 **https://haennah62.github.io/travel-map/**

## 이런 지도입니다
- 시·도 경계를 직접 그린 **일러스트 지도** (지도 타일 API 안 씀)
- 관광지는 카테고리별 이모지 — 🏖️ 바다 · 🏘️ 마을 · 🌿 자연 · 🍢 시장 · 🏛️ 역사 · 🗼 전망 · ☕ 카페 · 🎡 테마
- 왼쪽에서 **지역** 고르면 그 지역으로 확대
- 위쪽 **🚄 KTX역 / 🚂 기차역** 을 누르면 전국 역이 지도에 표시
- 관광지를 누르면 **가까운 지하철역·KTX역까지의 거리**와 **주변 맛집·카페**가 나옴

## 데이터
| 항목 | 출처 |
|---|---|
| 시·도 경계 | 통계청 행정구역 경계 (단순화) |
| 관광지 좌표 · 주변 맛집 · 지하철역 | 카카오 로컬 API |
| 설명 · 사진 | 한국어 위키백과 |

관광지 목록은 **공식 추천 · 블로그 후기 · SNS 인기** 세 갈래로 각각 조사한 뒤,
**두 곳 이상에서 공통으로 나온 곳만** 골라 담았습니다.

## 로컬에서 보기
```bash
python -m http.server 8501    # → http://localhost:8501
```

취미로 만든 개인 프로젝트입니다.
